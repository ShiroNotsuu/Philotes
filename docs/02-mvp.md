# Philotes · MVP

## 目标

让用户在一个具体时刻感受到：

> “它真的记得我，而且记得的那件事，让我觉得被理解。”

## 第一版范围

### 1. 聊天

- 一个稳定的桌面聊天窗口。
- 保持人格连续性和温和语气。
- 支持文字输入；语音、头像和复杂角色动画暂缓。

### 2. 记忆抽屉

- 显示“它记得什么”。
- 每条记忆包含：类型、内容、来源日期、可信度、原始上下文入口。
- 用户可以编辑、隐藏、删除，删除时同步从检索索引移除。
- 记忆分为：事实、偏好、承诺、人物、日期、待确认。

### 3. 记忆闪回

- 与当前话题相关时才出现。
- 一次一条，最多一天一次主动浮现。
- 显示“为什么想起”：关键词、时间或共同经历。
- 用户可以选择“现在不提”“以后别提”“忘掉”。

### 4. 重要日子与未完成的话题

- 记录重要日期、答应过自己的小事、没聊完的话题。
- 不做排行榜、不做亲密度分数。

### 5. 三个安全动作

第一版只允许：

- 打开一个已安装的应用。
- 创建一条备忘录。
- 设置一个提醒。

每个动作都必须先预览、由用户确认，并保留撤销入口。

## 不做

- 不读取屏幕内容。
- 不静默操作其他应用。
- 不自动发送消息。
- 不做健康或心理诊断。
- 不做亲密度、依赖度、忠诚度等分数。
- 不默认把聊天内容上传云端。

## 第一版成功标准

- 用户能在一周内至少体验一次“它想起了一件我忘了的小事”。
- 用户能清楚看到每条记忆从哪来。
- 用户能一键让一条记忆消失，并确认它不再被检索。
- 任何一个自动动作都能被拒绝或撤销。

## 下一步待定

- 第一版优先记：偏好、承诺、人物、日期，还是原话。
- 首发只做 macOS，还是同时考虑 iPad。
- 记忆检索先做关键词 + 时间，还是直接上本地语义索引。
