# Philotes · 当前界面架构

## 应用壳

macOS 使用隐藏标题栏的单一窗口。

- 底层：星海分页铺满整个窗口，星系与网格延伸到侧栏背后。
- 左侧：238pt 可折叠 Liquid Glass 工作区侧栏。
- 侧栏顶部使用与 macOS 应用图标同源的紧凑品牌图；Dock/Finder 使用带安全边距、透明外圈和玻璃高光的版本。
- App 启动和重新激活时会同步设置 `NSApplication.applicationIconImage`，避免 Dock 沿用旧进程或图标缓存中的空白占位图。
- 右侧：当前功能页，内容浮在宇宙画布上。
- 悬浮层：右下角对话窗。
- 整页模式：对话覆盖工作区，保留明确的收起按钮。

## 分页

### 星海

页面采用上下结构：

- 顶部：简化为“星海”、一句短说明和紧凑的智能体切换胶囊。
- 底部：占满剩余空间的统一宇宙。
- 顶部内容放入独立圆角液态玻璃悬浮栏，悬浮在星系图谱之上。
- macOS 26+ 使用原生 `glassEffect`，旧系统回退到深色 `ultraThinMaterial`。
- 悬浮栏通过边缘高光和柔和阴影与星系分开，不再铺整块矩形模糊背景。
- 顶部不再显示眉题、智能体数量、当前角色或重复摘要。
- 所有智能体星系位于同一个坐标空间，而不是独立卡片。
- 智能体恒星使用不等距、非网格的散落布局；位置由智能体 ID 的稳定扰动生成，每次重绘保持一致。
- 每个星系包含索引、人格、记忆、时间线、日记、维护六个分类节点；悬停分类或记忆星会显示 Markdown 预览。
- Markdown 预览浮层固定在顶栏下方，与液态玻璃悬浮栏保持安全间距。
- 宇宙背景由窗口最底层渲染，不局限在侧栏右侧的内容区域。
- 每个星系中央显示智能体图标；悬停出现编辑按钮，可修改图标与颜色。
- 记忆是围绕核心的可交互星点；悬停放大、发光，并显示标题。
- 记忆与智能体恒星之间始终绘制直线。
- 记忆之间有关联时绘制虚线，为后续 Obsidian 式图谱关系预留。
- 支持触控板缩放和 55%–240% 的按钮缩放；缩放只使用无过冲的惯性减速，不回弹。
- 支持鼠标拖拽平移；背景网格、星系、记忆节点和连线同步移动。
- 拖拽带有基于预测位移的短惯性，并限制平移边界。
- 底部缩放比例按钮同时复位缩放和平移。

### 智能体

- `从聊天记忆导入智能体` 与 `创建智能体` 并排在页头；导入按钮使用同样的圆角形状和弱化灰色样式。
- 导入窗口标题为“在这里唤醒我”，要求填写 API 并选择文本、Markdown 或 JSON 聊天记录。
- 分析期间显示分段读取、合并人格与记忆、写入心智库、执行第一人称唤醒等进度。
- 当前聊天智能体横幅。
- 智能体卡片网格。
- 创建智能体采用三步向导：我是谁 → 谁来帮助我思考 → 我是怎么样的。
- 第一步填写名字、头像和星系颜色；头像可选 Emoji 或上传本地图片。
- 第二步配置该智能体独立的 API。
- 第三步用选项胶囊设置关系、性别、年龄、性格、说话方式和折叠的高级细节。
- 选项按内容宽度连续向前堆积，仅换行时断开；不使用会被均匀拉开的等宽网格。
- 每个主要人格项都有“自定义…”；展开后用自然语言补充。
- Emoji 选择器提供一组预设 Emoji，同时提供“上传图片 / 更换图片 / 改用 Emoji”入口。
- 上传图片保存在本地应用目录，卡片、星海核心、聊天头像、悬浮窗与账户页统一读取。
- 每张智能体卡片都可编辑头像、星系颜色和 API。
- 每个智能体拥有独立消息和记忆。
- “模型连接”选择器提供暂不配置、DeepSeek、自定义兼容接口。
- DeepSeek 自动填入预置地址与模型；自定义接口显示地址、模型和密钥字段。
- 智能体卡片和当前聊天横幅显示当前 API 类型。
- 每张智能体卡片的“更改智能体设定”可同时修改图标、颜色和 API。

### 账户

- 页面说明固定为“查看我的账户和使用情况”。
- 页头右侧提供“编辑资料”按钮，打开个人资料设置。
- 个人资料设置支持本机昵称、选择/更换头像和移除头像；昵称会同步显示在账户页与侧栏底部。
- 账户页本体只展示头像，头像本身不再是设置按钮。
- 用户头像、本地账户状态和本机运行状态。
- 模型请求累计、智能体数量、记忆节点。
- 服务端账户字段占位：显示名称、邮箱、账户编号、云端同步。
- 我的智能体头像列表，点击可切换当前智能体。

### 侧栏底部

- 工作区只保留星海和智能体两个导航入口。
- 底部用户头像进入账户页。
- 用户头像下面保留独立设置按钮。
- 折叠侧栏时，两个入口缩成头像与齿轮图标。

### 设置

- 陪伴方式、外观与减少动态效果。
- 本地数据库、敏感记忆与凭据边界。
- “智能体心智库”入口会打开 `~/Library/Application Support/Philotes/AgentVaults/`，其中每个智能体目录都可单独作为 Obsidian vault 打开。
- 设置内容最底部显示低调的制作署名“由ResetSophia开发”。

## 浮动对话

- 默认宽 342pt、高 58pt。
- 鼠标悬停或输入内容时扩展到 430×366pt。
- 显示当前最近智能体与最近消息。
- 展开按钮进入整页对话。
- 整页对话右上角提供收起按钮。
- “整页”指侧栏右侧的内容区，不覆盖工作区侧栏。
- 侧栏“最近”与“新对话”打开同一内容区对话页。
- 每次重新进入整页对话或切换智能体时，会等 `LazyVStack` 完成首帧布局后定位到“最新消息”底部锚点；不需要用户再从最上方手动翻下来。
- 悬浮聊天与整页对话共用真实的流式回复状态。
- 生成过程中发送按钮变为停止按钮；停止后不保存未完成回复。
- 未配置 API 时发送失败会保留输入框内容，并显示明确错误。
- 智能体第一次成功回复后，聊天内容中央短暂出现“人格已激活”悬浮提示。
- 回复中的 `/(情绪与神态;.情绪值)/` 在聊天中显示为独立系统提示条，正文气泡去掉整个元数据结构。
- 旧格式 `/(动作与神态)/` 仍兼容，但没有情绪值，不进入曲线。

## 对话侧栏

- 整页聊天右侧栏最上方显示当前智能体档案。
- 基础信息包括 Emoji、名称、关系、模型和 API 类型。
- 人格档案显示关系、性别、年龄感、性格、说话方式、主动程度、情感表达和称呼。
- 有额外自然语言描述时显示在“自定义描述”区域。
- 没有人格 Markdown 的旧智能体仍显示基础信息，并注明尚未生成独立人格档案。
- 情绪曲线显示最近 18 条带情绪值的 assistant 回复。
- 曲线从 `-100` 低落区间延伸到 `+100` 高涨区间，显示平均值和当前区间。
- 还没有情绪采样时显示“等待第一次采样”；旧消息不会被补造为中情绪。

## 对话工具栏

- 右上角搜索按钮点击后在左侧展开搜索输入栏。
- 搜索当前智能体的聊天与记忆内容，结果按两列分组，不再跨智能体搜索。
- 点击聊天结果会关闭搜索栏并滚动到对应消息。
- 三点菜单包含“智能体设置”和红色“忘记我”。
- “忘记我”弹出不可撤销确认；确认后删除该智能体及全部相关内容。
- 搜索、三点和收起按钮使用一致的深色圆角遮罩底。

## Mac 操作确认

- 智能体提出动作时，聊天底部出现蓝色边框确认卡。
- 卡片列出每个动作的标题和参数，并提供“取消”“允许一次”“执行整项任务”。
- 基础动作显示应用名称、Bundle ID 或网页地址；AppleScript 会显示完整源码，点击会显示坐标与按钮，输入会显示完整文本，快捷键会显示组合键，截图会明确标注是否读取 OCR。
- 执行期间按钮替换为进度状态，发送框暂时不可用。
- 悬浮聊天使用相同确认卡的紧凑版本。
- 执行结果先作为标准 `tool` 消息回传模型；最终仍由智能体以带情绪动作前缀的正文回写聊天和 SQLite。模型暂时不可用时才显示本地整理结果。
- 如果当前任务还有依赖步骤，模型可在结果之后提出下一批动作；选择“允许一次”时每批都会出现新确认卡，选择“执行整项任务”时安全步骤自动推进。一轮最多 3 批。
- “执行整项任务”会连续执行安全的打开、切换、读取与截图步骤；AppleScript 和键鼠输入仍会单独停下来要求确认。
- 设置页“数据与隐私”中可关闭 Mac 操作请求；“完整 Mac 操作能力”默认关闭，开启后会把当前实现的 AppleScript、键鼠和屏幕快照全部提供给智能体。
- 完整能力开启后可查看实时权限徽章，并打开“辅助功能”和“屏幕录制”系统设置；键鼠事件由 `CGRequestPostEventAccess()` 请求，AppleScript 的自动化权限由系统在首次控制目标应用时询问。

## 动效原则

- 动画表达空间关系，不制造持续干扰。
- 侧栏折叠：弹簧曲线，响应约 0.32 秒。
- 页面切换：约 0.18 秒淡入和轻微缩放。
- 悬停：约 0.12–0.16 秒，位移不超过 2pt，缩放不超过 1.2%。
- 记忆星悬停：放大、增强光晕并显示名称。
- 宇宙缩放：双指跟手，释放后直接停在目标比例；按钮操作使用惯性减速曲线。
- 宇宙平移：直接跟手，松手后短距离惯性减速。
- 背景小星点：独立视差层，按拖拽距离约 22% 跟随，并按缩放变化约 18% 跟随。
- 按钮与标签页：统一使用小型缩放、亮度和阴影反馈。
- 开启“减少动态效果”时，时长压缩为几乎即时。

## Stage Manager

- Liquid Glass 侧栏不使用整块交互玻璃，避免系统窗口快照复用旧的动态玻璃层。
- App 激活和主窗口尺寸变化时重建玻璃表面；sheet 打开期间跳过。
- 重新前台前强制刷新窗口绘制和阴影，减少旧缩略图短暂停留。
- **2026-10-31 修正**：不再响应所有窗口的 key 变化；sheet 打开期间跳过侧栏玻璃重建。
- 主窗口 resize 或 App 激活后的玻璃刷新延迟到当前布局周期之后，避免布局递归和焦点抖动。
