# app

Philotes 的 macOS 原生 SwiftUI 应用源码。

- `Sources/PhilotesApp.swift`：应用入口与菜单命令
- `Sources/RootView.swift`：应用壳、页面路由和侧栏状态
- `Sources/SidebarView.swift`：可折叠的工作区导航
- `Sources/ConstellationPage.swift`：跨智能体的记忆星系总览
- `Sources/AgentsPage.swift`：智能体选择、创建与切换
- `Sources/FloatingChatView.swift`：右下角悬浮对话
- `Sources/ConversationPage.swift`：整页对话
- `Sources/PresencePage.swift`：情绪与人格可视化
- `Sources/SettingsPage.swift`：隐私、陪伴与外观设置
- `Sources/DatabaseStore.swift`：SQLite 数据层与 AppModel
